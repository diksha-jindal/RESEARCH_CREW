# Agentic AI
- Agentic AI refers to systems in which a language model plans, decides, and acts toward a goal with limited step-by-step human instruction.
- An agent typically combines a language model with tools, memory, and a loop that observes results and chooses the next action.
- Common agentic patterns include tool use, planning, reflection, and routing work between specialised agents.
- Agentic systems can complete multi-step tasks such as research, data analysis, and customer support triage.
- Because agents take actions, they need guardrails such as permission limits, logging, and human approval for sensitive steps.
- Evaluating an agent means measuring task success, cost, latency, and safety, not only the quality of a single response.
