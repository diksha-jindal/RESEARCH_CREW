# No-Code and Low-Code Agent Building
- No-code and low-code platforms let teams build agents through visual designers and configuration instead of writing full applications.
- Microsoft Copilot Studio is an example of a low-code tool for building conversational agents that connect to business data and workflows.
- Low-code agents are quick to prototype and suit simple, well-defined workflows such as FAQ answering and approvals.
- Code-based frameworks give more control over orchestration, testing, and custom tools at the cost of more development effort.
- Many organisations combine both, using low-code for simple requests and Python for complex multi-step logic.
