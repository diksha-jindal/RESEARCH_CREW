# Evaluating LLM Applications
- Evaluating a language model application requires test cases that reflect real usage, not only generic benchmarks.
- Common metrics include factual accuracy, citation correctness, relevance, latency, and cost per task.
- Automated checks can verify that every claim in an output is supported by a cited source.
- Scores from an automated judge should be spot-checked by humans because judges can be biased or wrong.
- Tracking metrics across runs reveals regressions when prompts, models, or tools change.
